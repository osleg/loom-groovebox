Loom CAFA v4: Windows reassembly and safe installation

Download all three parts into the same folder:
  Loom-CAFA-v4.apk.001
  Loom-CAFA-v4.apk.002
  Loom-CAFA-v4.apk.003

These are RAW parts, not ZIP files or individually installable APKs.

In Windows Command Prompt (cmd.exe), change to that folder, then run this
single command on one line:

copy /b Loom-CAFA-v4.apk.001+Loom-CAFA-v4.apk.002+Loom-CAFA-v4.apk.003 Loom-CAFA-v4.apk

The result must be exactly 52,437,040 bytes. Check it with:

certutil -hashfile Loom-CAFA-v4.apk SHA256

Expected SHA-256:
402e9a3cabaa7dc2a69c6d5824021f9cef9e3739ce535ac0ccd9f2af3bd03701

Then transfer/install Loom-CAFA-v4.apk on Android. Do not install a .001/.002/.003
part, and do not rename a single part to .apk.

IMPORTANT
- Install alongside the working old app. This app is named Loom CAFA v4,
  package com.groovebox.cafa.v4, version 3.2.19-cafa.4, code 390.
- The original signing key was lost. The separate package avoids uninstalling
  the old app or erasing its projects. Projects are not imported automatically;
  export/import through Loom and keep the originals.
- Disconnect/close older Loom/CAFA apps before connecting the v4 FM1 link.
- Requires matching protocol-v4 firmware. Old v3 firmware will not connect.
- Turn volume down and use a direct data cable/stable power. Start with a
  disposable project and wait for “FM1 synchronized” before playing.
- REC is unavailable; complete recorded-step synchronization is a follow-up.
- LFO, FX, ARP, pattern controls and held-step edits are mapped. Full Skiff
  workflow parity, preset loading, sampling and arrangement stay on the phone.
- Firmware omits factory instrument sample sets to fit; user slots are retained.
- No physical flash, phone install or audio listening qualification was done.
