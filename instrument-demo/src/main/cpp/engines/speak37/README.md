# Speak37 for FM-1 Instrument

This is the pitched spoken/sung instrument adapted from [Speak37 by M. Geisler (genkigenki/makkuro), commit 81fa061b](https://github.com/genkigenki/Speak37/commit/81fa061b40e6b6305e3672c671ead2552c9b8569). The dry LPC playback core adapts the frame reader, excitation, filtering, and nine mode profiles from `firmware/src/sp_dsp.c` (GPL-3.0-only). Skiff supplies keys, chords, transport, the amplitude envelope, modulation, and effects. Hold SING to sustain the word's vowel and release to continue its consonants. ONE SHOT and LOOP are also available. CHOIR uses three detuned/formant-shifted layers per note. The presets in `eng_speak37.c` are original.

The generated `thirdparty/sp_vocabulary.h` contains 2,469 LPC-encoded words and 351,622 frame bytes from this revision's FM-1 build, using its 572 English and 528 German dictionary entries. Browse 64 word labels at a time. The final window overlaps the preceding one to keep all slots valid. The donor's [per-component licensing](https://github.com/genkigenki/Speak37/blob/81fa061b40e6b6305e3672c671ead2552c9b8569/LICENSING.md) identifies the cached eSpeak NG-derived frames as GPL-3.0-only and the TMS5220 coding tables and excitation chirp as BSD-3-Clause from MAME (Frank Palazzolo, Couriersud and Jonathan Gevaryahu). The original eSpeak NG voices and TI recordings are not bundled.

Some displayed lexicon entries derive from [FrequencyWords by Hermit Dave](https://github.com/hermitdave/FrequencyWords) via Speak37's filtered English and German lists, based on the OpenSubtitles 2018 corpus. These label data retain [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Instrument picks the FM-1-sized set, combines duplicate labels from the different voices as separate entries, and groups the words into 64-position windows. The license notices for code, MAME data and the lexicon are in this directory.

Regenerate with `python3 generate_vocabulary.py /path/to/pinned/Speak37`. The generator reads the donor's cache and uses its selector and metadata logic. It excludes the original sentences, MOPE behavior, drum sequencer and arrangements.
