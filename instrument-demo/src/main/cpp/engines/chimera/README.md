# CHIMERA vocal tract

CHIMERA uses the vocal tract, glottis, English syllable planner, beat gestures, seal, and songbird from [Shan-Sherif's FM-1 port at 5a9e5f7](https://github.com/shan-sherif/fm-1-chimera-vocal/tree/5a9e5f7af4ae8ce954ff39735274afe5593b7796) of [Jameson Hodge's CHIMERA Vocal Synth](https://github.com/jamesondh/chimera-vocal-synth). The vendor files in `thirdparty/` retain their copyright notices. The two MIT license files cover the original model and the C port. The CMUdict notice covers the donor's 477-entry pronunciation table. The bird's waveform table represents simulated syrinx valve openings, and the rest of the sound data describes the anatomy and speech gestures. The engine uses no recordings.

The donor's waveguide runs at 44.1 kHz with the male, female, and child tract geometries. The physical vowel pad maps **OPEN** and **FRONT** to formants. **ENGLISH** uses eleven selectable syllables with the donor's consonant and vowel timing, and **BEATBOX** plays all ten physical percussion gestures. Select a fixed hit or use **BY KEY** to cycle the hits by MIDI note number. **SEAL** and **SONGBIRD** use the donor's playable physical models. Each track runs one voice. Skiff provides the envelope, notes, sequencer, modulation, effects and storage. The seven bundled presets are original settings.

The app assigns the appropriate playback labels to each mode. The English planner and vowel pad use thread-local table selection so the calling audio thread owns that state. The app contains the enumerated syllables and playable animal voices. The donor's free-text authoring, automated creature calls, songs, illustrations and separate beat sequencer are outside these presets.
