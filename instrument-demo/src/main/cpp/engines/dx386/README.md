# 386 DX for FM-1 Instrument

[386 DX Engine](https://github.com/seajaysec/386-DX-ENGINE/commit/595eb7d9e9200e97b7fbc09ff7e1fdb771bf5f11) supplies the GPL-3.0-only singing layer and English/Klatt adaptation. `thirdparty/dx` preserves its host C library with one portability change. The forced-include header loads the C math declarations before aliasing math names. `thirdparty/espeak` contains the donor-prepared [eSpeak NG 1.52.0](https://github.com/espeak-ng/espeak-ng/commit/4870adfa25b1a32b4361592f1be8a40337c58d6c) implementation and its English assets (GPL-3.0-or-later), plus the generated Unicode property subset (Unicode Data Files license). `thirdparty/provenance` contains the donor preparation script and pruning list for reproducing those sources. Component notices and license texts are here.

**PHRASE** selects one of the four original short lines or **USER**, the English line entered in Instrument. **SYLLABLE** selects which syllable the next MIDI or sequencer note sings, starting at zero. An index beyond the available syllables cycles through the line. **BODY**, **BREATH** and **EDGE** adjust Klatt's tract and source. **GLIDE** controls pitch transitions, **LENGTH** sets the articulation time, and **HOLD** chooses between a looped vowel sustained by the gate and one-shot playback. A held vowel follows MIDI pitch, bend and Skiff modulation, and the key release lets the clip continue to its ending as Skiff releases the voice.

One native worker owns the stateful donor library. The four original default sounds start with warm clips at five root pitches. A fresh syllable or a new set of articulation values renders asynchronously on first use, then reuses up to two clips per track and voice. A note may begin a little later on a cache miss. Within each octave window the player resamples from its root and pitch glides travel across that clip. Unusually high or low notes beyond the root windows shift formants further. Four voices per track use Skiff's envelopes and effects. The worker output is temporary RAM data with no packaged PCM sound bank. The 305,792 bytes of built-in eSpeak language assets include its phoneme synthesis data. The KaraokeBot UI, song library and branding assets are excluded.

Run `build-host.sh /path/to/libdx386.a` for a host archive. Android builds the matching library with `build.cmake`.
